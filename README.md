# Vim configuration

Standalone-Vim-Konfiguration ohne externe Plugins, mit Catppuccin-Farben,
modularer Statusline und vertrauten Editor-Keybindings.

**[Vollständige Dokumentation](https://vim-config.readthedocs.io/en/latest/)** ·
[Arch-Paket](https://vim-config.readthedocs.io/en/latest/packages/) ·
[Keybindings](https://vim-config.readthedocs.io/en/latest/keybindings/) ·
[Dotfiles-Handbuch](https://arch-dotfiles.readthedocs.io/en/latest/)

```bash
curl -fsSL https://raw.githubusercontent.com/MichaelWeissDEV/dotfiles/main/install.sh | bash -s -- vim
```

Paket: `arch-dotfiles-vim`. Einstieg: `~/.config/vim/vimrc`, verlinkt als `~/.vimrc`.
Standalone-Installation und Bedienung sind im Handbuch beschrieben.
Hier entwickeln und auf `main` pushen; nach erfolgreichem Registry-Build mit
`sudo pacman -Syu` aktualisieren. Lokale Builds: [PACKAGING.md](PACKAGING.md).
